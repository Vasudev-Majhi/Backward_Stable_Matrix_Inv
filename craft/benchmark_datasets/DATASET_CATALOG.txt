1. KARATE — Zachary's Karate Club Social Network
   Nodes : 34  |  Edges : 78  |  Weighted: No (unit R=1)
   Domain: Social Network
   File  : karate.edges
   Source: W.W. Zachary, "An information flow model for conflict and fission in
           small groups," J. Anthropol. Res. 33, 452-473 (1977)
   Get   : networkx.generators.social.karate_club_graph()
           SuiteSparse: https://sparse.tamu.edu/Newman/karate
   Notes : Classic benchmark for community detection. Two factions (nodes 0-16
           = instructor side, nodes 17-33 = administrator side) split into two
           communities. Default test: inject 1A at node 0, ground node 33.

2. DOLPHINS — Bottlenose Dolphin Social Network
   Nodes : 62  |  Edges : 159  |  Weighted: No (unit R=1)
   Domain: Biological / Animal Social Network
   File  : dolphins.edges
   Source: D. Lusseau, K. Schneider, O.J. Boisseau, P. Haase, E. Slooten,
           S.M. Dawson, "The bottlenose dolphin community of Doubtful Sound
           features a large proportion of long-lasting associations,"
           Behav. Ecol. Sociobiol. 54, 396-405 (2003)
   Get   : SuiteSparse: https://sparse.tamu.edu/Newman/dolphins
           GML: https://github.com/RishujeetRai/DolphinsSocialNetworkAnalysis
   Notes : Undirected network of frequent associations between 62 dolphins off
           Doubtful Sound, New Zealand. Two gender-based communities.

3. LES MISERABLES — Character Co-appearance Network
   Nodes : 77  |  Edges : 254  |  Weighted: Yes (integer counts, range 1-31)
   Domain: Literary / Humanities Network
   Files : lesmis.edges, lesmis_nodes.txt
   Source: D.E. Knuth, "The Stanford GraphBase: A Platform for Combinatorial
           Computing," Addison-Wesley (1993)
   Get   : JSON: https://raw.githubusercontent.com/vega/vega-datasets/master/data/miserables.json
           SuiteSparse: https://sparse.tamu.edu/Newman/lesmis
   Notes : Characters are nodes; edges connect characters appearing in the same
           chapter. Edge weight = number of shared chapters (used as conductance
           in the resistor network model). Most connected node: Valjean (ID 11).

4. POLBOOKS — US Political Books Co-purchase Network
   Nodes : 105  |  Edges : 441  |  Weighted: No (unit R=1)
   Domain: Recommendation / Political Science Network
   Files : polbooks.edges, polbooks_nodes.txt
   Source: V. Krebs (2004), unpublished. Compiled from Amazon.com co-purchase
           links for political books around the 2004 US presidential election.
   Get   : SuiteSparse: https://sparse.tamu.edu/Newman/polbooks
           https://networks.skewed.de/net/polbooks (CSV download)
   Notes : Books clustered into liberal (blue), conservative (red), neutral
           (gray). Good community structure. Nodes have book titles in
           polbooks_nodes.txt.
